# 企業紹介HP レイアウト案

企業紹介を目的にするなら、訪問者が最初に「何をしている会社か」「どんな実績や強みがあるか」をつかめる構成にすると、会社への信頼につながりやすくなります。
現在のページは Top → Message → Description → Mission → Recruitment → Information の順です。社長メッセージを読む前に事業内容や施工実績が分かるよう、次の順序を提案します。
Hero → 会社の強み・数字 → 事業内容 → 施工実績 → 安全・品質 → Message／Mission → 採用情報 → 会社情報・お問い合わせ

| 優先度 | レイアウト案 | 期待できること |
|---|---|---|
| 高 | **Topに会社の特徴と導線を集約**。短いキャッチコピー、現場の写真、事業内容・施工実績・採用情報へのボタンを配置 | 初めて訪れた人が、会社の概要や次に見る情報をすぐ把握できます |
| 高 | **施工実績を独立したセクションにする**。現場写真と、工事の種類・役割・成果をカード形式で紹介 | 技術や経験を具体的に示せます。社名や現場名を掲載する場合は公開可否の確認が必要です |
| 高 | **事業内容を写真付きで整理する**。現在の工事カードを、各工事の短い説明と写真が対応するレイアウトにする | 仕事内容が伝わりやすくなり、文章だけの印象を減らせます |
| 中 | **安全・品質への取り組みを見せる**。安全対策、施工前後の確認、教育・資格取得支援などを写真と短文で紹介 | 鉄道インフラを支える仕事で重視される責任感や体制を説明できます |
| 中 | **会社情報と問い合わせをページ末尾にまとめる**。会社概要、所在地、電話、地図、採用問い合わせを整理 | 連絡先を探しやすくし、ページを見た後の行動につなげられます |

# ポイント
- Messageは事業内容や実績の後に置く
  現在のMessageは比較的長いので、最初に会社の事業と実績を理解してもらってから読む流れが自然です。冒頭には短い会社紹介だけを置き、詳細な挨拶は後半に回す方法があります。

- 施工写真は、写真だけで終わらせない
  「何の工事か」「どんな役割を担ったか」を添えると、写真が会社の実績を伝える材料になります。同業他社の例でも、施工実績を鉄道工事などの分野別に整理しています。[新生テクノスの施工実績](https://www.stknet.co.jp/4recruit/graduates/works/)・[京成電設工業の施工実績](https://www.keidenko.co.jp/works/)

- セクションごとの見せ方に変化をつける
  すべてを同じカードの並びにせず、事業内容は写真と説明の2カラム、実績は写真カード、安全・品質は短い項目、会社情報は表形式など、内容に合ったレイアウトにします。背景色や余白、見出しのルールは統一すると、ページ全体にまとまりが出ます。

- スマホでは読む順番を明確にする
  写真と文章を縦に並べ、カードは1列、電話番号はタップで発信できる形にします。施工写真は全体を見せる表示と、写真を大きく確認できる表示を使い分けると、縦横比の異なる写真にも対応しやすくなります。

参考にした公式サイトでは、東邦電気工業が「企業情報・事業内容・施工事例・教育訓練」を分け、新生テクノスや京成電設工業が施工実績を工事分野ごとに整理しています。また、JR東日本の電気システムインテグレーションオフィスは「会社・仕事・人・採用」への導線を設けています。[東邦電気工業](https://www.toho-elec.co.jp/)・[JR東日本 電気システムインテグレーションオフィス](https://www.jreast.co.jp/esio/)
まず優先するなら、①Topで会社の特徴を明確にする、②施工実績を追加する、③事業内容を写真と説明のセットで整理するの3点です。採用情報は引き続き掲載しつつ、会社紹介としては事業と実績を主役にすると、目的に沿ったページになります。
